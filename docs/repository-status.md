# Repository status

Last updated: 2026-07-30

## Available now

- The Chinese bachelor-thesis PDF under an English filename.
- The oTree experiment source and local ESG-report stimuli.
- A complete English translation of the experiment audit and variable guide.
- An English guide to the participant-facing instructions and workflow.
- Provider-neutral configuration placeholders for the optional AI-assisted condition.
- Documentation of the generated ESG-report provenance and current reproduction limits.

## Not yet available

- Raw or processed participant data.
- The final statistical-analysis scripts and output tables.
- A verified end-to-end reproduction environment matching the original study computer.

The missing analysis materials have not yet been recovered because the original computer is temporarily unavailable. This repository does not fabricate substitutes for those files. For an urgent research request, contact the author through the associated academic homepage.

## Safety actions applied

- No credential, token, local `.env` file, service-specific endpoint, provider identifier, or fixed model name is tracked.
- API configuration uses only the generic variables `API_KEY`, `API_ENDPOINT`, and `API_MODEL`.
- Local databases, participant exports, generated caches, and common oTree runtime artifacts are excluded.
- English documentation is clearly separated from the Chinese materials actually used in data collection.
- Researcher-created ESG PDFs are identified as experimental stimuli rather than official company disclosures.

## Interpretation boundary

The thesis sample only met the minimum planned statistical-power requirement. The reported patterns should be treated as exploratory, predictive, or correlational evidence and should not be reused as established conclusions. Independent replication is recommended.

## Planned update

When the original analysis computer becomes available, the next archive update should add the analysis scripts, a data dictionary, software-version information, and—subject to research-ethics and privacy constraints—an appropriately de-identified replication dataset or access statement.
