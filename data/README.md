# Data availability

Participant-level data are not included in this public repository. The local oTree SQLite database and runtime files were deliberately excluded to prevent accidental disclosure of research records.

The thesis reports aggregate descriptive statistics, regression results, and sample definitions. Questions about data availability can be directed to the author through [the project website](https://jhchen4future.github.io/) or GitHub. Any future release should first be checked for privacy, consent, and institutional requirements and should include a data dictionary.
